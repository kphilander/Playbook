# Read the library with an AI assistant

Start with the [shared reading guide](../docs/ai-guide.md), or open [catalog.json](catalog.json) to select a collection. Reading works through GitHub and raw file URLs without cloning, installation, accounts, or MCP. The [starter tasks](tasks.json) are optional examples.

## Catalog v1

`schemaVersion: 1` identifies the catalog structure. Collection IDs are stable discovery identifiers: keep them when titles change. The catalog indexes collections and links existing manifests; it is not an exhaustive list of files or a content-quality audit.

| Field | Meaning |
|-------|---------|
| `repository`, `pathBase` | Source location and path interpretation. Local paths are relative to the repository root. |
| `guide`, `fieldGuide` | Reading guide and this field reference. |
| `collections[].id` | Stable collection identifier. |
| `sourceRole` | Explicit source label: `configuration`, `guidance`, `authored-content`, `preferred-edition`, `earlier-and-alternate`, `experimental`, `generated-snapshot`, `implementation`, or `demonstration`. Preference applies only to the coverage stated in `selection`. |
| `title`, `description`, `selection` | What the collection contains and its source-selection limits. |
| `path`, `entry`, `readFiles` | Collection directory, readable starting file, and useful direct sources or context files. Context files may be in another collection. |
| `manifests` | Existing JSON indexes with `path`, `kind`, `pathsRelativeTo`, derived `itemCount`, and `itemIdentifier`. Follow their own item/file records. |
| `formats` | Available format examples: file extension plus a verified repository path. These are source/artifact examples, not a promise that every item has every format. |
| `languages` | Documented codes and source paths from JSON metadata, Markdown frontmatter, or HTML `lang`. Evidence is file-level, not proof of full collection translation or qualified language review. `null` means unspecified. |
| `edition` | An explicit edition value and its source, currently provided by the editorial manifest. `null` means unspecified; no edition is inferred from file modification or generation time. |
| `relatedSources` | Optional external source locations. Website editions and packages remain separate from this repository. |

Editorial file paths are relative to `collateral/editorial/`. Its resource keys are item IDs; its file records include hashes and sizes. Read `referenceNotes` and `sources` alongside the HTML/text. Style-study paths are relative to `collateral/style-alternatives/`; use each entry's `id`. Asset-manifest `sourceUrl` paths are relative to the repository root; `id` alone is not unique across formats (for example, favicon SVG and ICO). Use `sourceUrl` to identify the file. Its `url` is a deployment path.

Pin the commit actually read. Resolve **all** paths, including manifests and language evidence, at that same commit. The catalog intentionally has no moving timestamp or self-referential commit hash. See [citation instructions](../docs/ai-guide.md#4-cite-what-you-actually-read).

## Maintaining discovery files

These commands are for maintainers changing the index; readers do not need to run them.

- `npm run generate:catalog` — build `catalog.json` from the small [collection map](collections.json) and existing metadata.
- `npm run check:catalog` — validate inputs and compare generated bytes with the committed catalog, without writing files. Fails on missing paths, malformed metadata, invalid identifiers, mismatched manifest formats/hashes, or stale output.
- `npm run test:discovery` — exercise determinism, failure cases, local discovery links, and the five short reading routes; also check the matching native skill pointers.

Add or update a collection in `collections.json`. `formatExamples` supplies actual paths, and `languageSources` names files with explicit metadata; never infer missing language or edition. Linked manifests contribute their recorded formats, counts, and edition where applicable. Supported manifest kinds are `editorial`, `assets`, and `style-studies`.

Keep the generated catalog under review with its map changes. The generator does not rewrite library content, regenerate artwork, install dependencies, fetch website editions, or create automation. Stable IDs and edition boundaries are part of the discovery contract.
