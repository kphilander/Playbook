# Changelog

All notable changes to Playbook are documented here.

Format follows [Semantic Versioning](https://semver.org/):
- **MAJOR** = breaking changes to brand identity or architecture
- **MINOR** = new content (chapters, jurisdictions, collateral)
- **PATCH** = corrections, regulatory updates, clarifications

## [Unreleased]

### Added
- `verticals/` — deployment maps by line of business: casino, sportsbook, online gaming, and lottery. Each playbook maps the player journey for its vertical and picks the guides, campaigns, myths, collateral, segments, and staff materials that fit, with jurisdiction-module pairing and scorecard measurement built in.
- `_taxonomy.yml`: new `vertical-playbook` content type, and a documented `verticals:` axis (land-based, interactive, sports, lottery) formalizing the tag jurisdiction modules already use.

### Changed
- Tier 1 is now named Everyday play throughout the brand book, messaging, taxonomy comments, slide deck, and hub. Tier 2 keeps the name Support and crisis.
- The positioning line for operator, regulator, and industry contexts is now "One open standard for responsible gambling". Player-facing Tier 1 copy describes what the content does instead, because chapter 4 bars "responsible gambling" there.

## [0.1.0] - 2025-02-20

### Added
- `_brand.yml` white-label configuration engine with two brand pillars (Open, Social), color palette, typography, helplines, tagline system, and tone configuration
- Brand book: 10 chapters covering introduction, brand foundation, personality, visual identity, voice and tone, messaging framework, accessibility, application guidelines, governance, and glossary
- Project infrastructure: README, CONTRIBUTING guidelines, CC0 license
- Two-tier brand architecture: Tier 1 (Everyday play) and Tier 2 (support/crisis, planned)
- Informed choice positioning: marketing-oriented voice, confident myth-buster tone, gambling-neutral stance
