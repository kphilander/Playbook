# Fonts

Vendored font binaries used by the build pipeline.

| File | Purpose |
|------|---------|
| `Inter-Variable.ttf` | Inter 4.001 variable font (wght 100–900, opsz 14–32). Used by [`collateral/render/build-logos.mjs`](../../../collateral/render/build-logos.mjs) to convert wordmark text to vector outlines at build time, so the emitted logo SVGs have no font dependencies. |
| `OFL.txt` | SIL Open Font License 1.1 for Inter (redistribution permitted with this notice). |

Inter is by Rasmus Andersson — https://rsms.me/inter/
