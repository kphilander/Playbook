# Photography Reference Prompts

Every reference image in [`photography.md`](../photography.md) is AI-generated
(Google `gemini-3-pro-image`, 4:3, 1K) and owned outright — no stock licensing.
The do/don't examples are controlled pairs: the same scene with exactly one
property changed (lighting intent, or social vs. solitary framing), so the
guideline being taught is the only variable.

To regenerate, rerun the prompt and save over the same filename.
