# Playbook repository context

Before content or implementation work, read [the shared AI guide](docs/ai-guide.md). It is the model-neutral reference for source precedence, factual limits, adaptation, privacy, checks, and release permissions.

Playbook Brand is an open, white-label system for player education. The formal name is Playbook RG; Playbook is its player-facing shorthand. Use [the collection catalog](ai/catalog.json) to find sources and edition labels. Reading through GitHub or raw URLs needs no installation or MCP connection. See README.md for the repository map and lib/README.md only when build work is requested. Inspect current files instead of relying on historical counts or availability claims.

The starter task definitions live in ai/tasks.json. The /brand-create command uses this same guide. Existing maintenance and jurisdiction workflows remain available, but must preserve the guide's factual, approval, and production boundaries.
