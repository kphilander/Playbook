Read the conditions

A more consistent comparison.

Every agent received a fresh context, the same required reading, three topic categories, copy limits, and a fixed card template. All were asked for high reasoning. Each submitted once, with text checks allowed and no image previews or coordinator creative feedback.

The coordinator sent each photography prompt verbatim to Google Gemini 3 Pro Image, with one 3:4 / 2K attempt per concept. The first returned image is used; all outputs and failures are retained. Model-authored copy and prompts are unchanged.

This compares copy and photography direction under shared inputs. It does not compare custom layout design. Google’s image variability, different model runtimes, and unequal token use remain limitations. GPT-5.4 was unavailable and is not scored.

Hidden names are a viewing aid, not a secured blind study: the model key remains in the files. No independent judging or winner is presented. Testing the value of a shared RG system requires a matched brief-only condition within each model; these examples alone do not establish that benefit or prove the Bitter Lesson.
